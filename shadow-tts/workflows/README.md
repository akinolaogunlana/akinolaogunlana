# Workflow Options

## Option A: GitHub Actions inference
Use `.github/workflows/shadow-tts-generate.yml`.

## Option B: Codespaces
Open this repo in GitHub Codespaces and run:

```bash
cd shadow-tts
python app.py
```

## Option C: External open hosting
Use Docker image from this repo and deploy to Render/Fly.io/HuggingFace Spaces.
